Classes d’encadrement des implantations scolaires

Recherchez une implantation scolaire par nom, code postal ou numéro FASE. Le fichier couvre Bruxelles et la Wallonie.

Les classes ED (encadrement différencié) et HED (enseignement spécialisé) sont des catégories réglementaires. Elles ne mesurent ni le nombre d’élèves ni la qualité d’une école.

Les formules FO et SO sont différentes : comparez les classes uniquement au sein d’une même formule. Le fichier ne contient pas de code NIS communal.
