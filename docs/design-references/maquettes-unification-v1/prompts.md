# Maquettes BelPulse — prompts et revue

Générateur intégré image_gen, compétence imagegen. Accueil utilisé comme référence de style pour les huit générations suivantes. Aucun fichier du site public ni du pipeline modifié.

## Limites de ces images

Ces PNG fixent une direction visuelle, pas un contrat de données. Ne pas recopier leurs chiffres, contours, photos, licences, formules ou catégories dans le site.

Points repérés : Bruxelles est incorrectement décrit comme une province dans la maquette Profils ; certaines classes d’âges de la pyramide sont répétées ; la croissance A-A et trimestrielle sont confondues dans certains libellés ; les cartes et leurs classes ne sont pas des géométries/données officielles ; quelques rubriques de la planche des thèmes diffèrent du menu validé. Certaines unités, sources et périodes ont été inventées par le générateur. Le plan fonctionnel et les métadonnées du pipeline font autorité.
